Get started with Rocket league

Download Guide

Welcome to your Rocket League journey!
This free-to-play game is available on multiple platforms, and getting started is easy. Follow these steps to jump into the action.

  1. Visit Epic Games Store.
  2. Click 'Get' to download the game for free.
  3. Install and launch Rocket League to create your account.

Beginner Tips

Ready to play?
Start with these tips to improve quickly as a beginner!

  • Practice boosting and aerials in training mode.
  • Learn basic controls like turning and jumping.
  • Play with friends to build confidence.
